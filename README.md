# M-TRANS Bus

Статический лендинг услуги размещения рекламы на задней части автобусов.

## Структура

```text
.
├── index.html              # Разметка и SEO-метаданные
├── assets/
│   ├── css/styles.css      # Стили и адаптивная версия
│   ├── js/main.js          # Формы и отправка заявки в Telegram
│   └── images/             # Изображения и favicon
└── robots.txt              # Правила индексации
```

## Локальный запуск

Сайт не требует установки зависимостей или сборки. Можно открыть `index.html`
напрямую либо запустить любой статический сервер:

```bash
python3 -m http.server 8000
```

После запуска сайт будет доступен по адресу `http://localhost:8000`.

Формы формируют текст заявки и открывают диалог с M-TRANS в Telegram.
