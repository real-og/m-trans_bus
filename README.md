# M-TRANS Bus

Лендинг услуги размещения рекламы на задней части автобусов для M-TRANS.BY.

## Запуск

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Структура

- `app/page.tsx` — контент, формы и интерактивные элементы лендинга.
- `app/globals.css` — визуальная система и адаптивные стили.
- `app/layout.tsx` — SEO-метаданные и Schema.org-разметка.
- `public/` — оптимизированные изображения и favicon.

Форма заявки формирует сообщение и открывает диалог с M-TRANS в Telegram. Контактные данные и ссылка на политику обработки персональных данных синхронизированы с действующими сайтами компании.
